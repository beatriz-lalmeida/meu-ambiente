# Meu Ambiente
Transformar ambientes inteligentes em experiências personalizadas, adaptando configurações às
preferências e necessidades de cada usuário.

## Tecnologias utilizadas
- Python
- SQLite
- SQL

## Funcionalidades desenvolvidas
- Cadastro e login de usuários
- Criação e gerenciamento de banco de dados
- Busca, edição e exclusão de dados
- Escolha de objetivos e configuração personalizada para o ambiente
  
## Desenvolvimento do projeto

### Banco de dados

Criação e organização do banco de dados para armazenar e gerenciar as informações dos usuários.

### Operações com dados

Implementação de funcionalidades para buscar, editar e excluir registros no banco de dados.

### Personalização do ambiente

Desenvolvimento da lógica para selecionar objetivos e apresentar configurações correspondentes às necessidades do usuário.
